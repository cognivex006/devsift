# Independent review checklist

- [ ] Reviewer is not task author, actor identity verified.
- [ ] Same task ID, branch commit and exact base SHA match submission.
- [ ] Source edit remains within declared file/contract ownership.
- [ ] Test commands actually executed, results reproducible, no fabricated evidence.
- [ ] Quality scan is read-only, legacy recommend-only, unknown cases unresolved.
- [ ] Relevant source-aware report location verified; BEFORE exact, AFTER labeled proposal.
- [ ] Two-sided effects captured; no broad logging rewrite/no forced upstream timing.
- [ ] Security outputs redacted in Markdown/JSON/SARIF/prompts, exceptions and debug output.
- [ ] No change to published artifact or release unless separately approved.
- [ ] Controller integration commit SHA verified and conflict result documented.
- [ ] Only after all above: status accepted, evidence ledger updated, prerequisite unlock allowed.
