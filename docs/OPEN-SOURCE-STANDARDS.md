# Open-source standards adopted

- Conventional Commits: https://www.conventionalcommits.org/en/v1.0.0/
- Semantic Versioning: https://semver.org/
- Keep a Changelog: https://keepachangelog.com/en/1.1.0/
- SARIF 2.1.0 interoperability: https://docs.oasis-open.org/sarif/sarif/v2.1.0/sarif-v2.1.0.html
- OpenTelemetry semantic conventions: https://opentelemetry.io/docs/specs/semconv/
- OWASP logging guidance: https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html

A *plan* has no released SemVer version. The kit name v6 denotes specification iteration only. Actual package version starts when a release is approved, based on API compatibility and rule severity migrations. Changelog Unreleased is updated as work is accepted, without arbitrary bump-per-task conventions.

Public code without an explicit license is not automatically open source. Choose and add a compatible LICENSE via a separately recorded owner decision before claiming OSI licensing or inviting unrestricted reuse.
