# Security Policy

DevSift is a pre-release development project. Security reporting should avoid public disclosure of exploitable details, credentials, access tokens, or customer source code. Use GitHub's private vulnerability reporting feature if it is enabled for this repository; otherwise contact the maintainer through a private channel agreed with the repository owner. No guaranteed response SLA is currently established.

Production-facing rules must not transmit source code or secrets to external services without explicit consent. `scan` and `review` are read-only; remediation is a separately approved action, especially for legacy code. Review new/legacy policy and redaction tests before enabling CI enforcement.
